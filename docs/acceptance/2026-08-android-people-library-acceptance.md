# Android 人物与媒体库导航真机验收计划

> 本文档是设备所有者执行真实验收的计划。实现者不得用自动化、构建或模拟器结果
> 代填真机通过结论。

状态：`NOT_ACCEPTED`。本文所有场景均需使用真实 Emby 服务器和 Android 物理设备验证；
自动化测试通过、APK 构建成功或模拟器结果均不能替代本验收。验收所用完整提交 SHA
由设备所有者在结果记录中填写。

## 1. 整体验收门槛

| 编号 | 测试场景 | 通过标准 |
| --- | --- | --- |
| G-01 | 记录验收环境 | 每次验收记录应用完整提交 SHA、构建类型、Emby Server 版本、服务器连接类型、匿名化媒体库标识及条目数、设备型号、CPU ABI、Android 版本、导航模式、屏幕刷新率和网络类型。服务器连接类型只写“局域网 HTTP”或“HTTPS”，不写主机名、IP、端口或完整 URL。 |
| G-02 | 准备真实数据样本 | 至少包含一个 1000 项以上的电影或电视剧媒体库、一个拥有 61 项以上本地作品的人物（跨越当前默认每页 60 项的边界）、电影/电视剧/单集演员数据、无头像或无简介人物、无本地作品人物、数字或符号开头项目、A-Z 项目、中文项目、自定义 `SortName` 项目，以及可区分的 STRM/普通媒体样本。每类样本的服务器端预期结果和总数可核对。 |
| G-03 | 执行结果记录 | 每个场景记录通过、失败或阻塞及证据；失败记录复现条件、实际结果和日志时间点。所有场景通过且第 8 节风险已关闭或明确接受后，才能把真实服务器/Android 验收标记为完成。 |
| G-04 | 保护验收数据 | 原始抓包、日志、崩溃报告和截图只保存在设备所有者控制的本机位置，不提交仓库。归档或提交的摘要必须先移除访问令牌、密码、服务器地址、用户名、媒体标题及截图中的可识别内容；只保留复现所需的脱敏字段、计数、状态码和时间点。 |

## 2. 演员人物页

| 编号 | 测试场景 | 通过标准 |
| --- | --- | --- |
| A-01 | 分别打开包含真实人物数据的电影、电视剧和单集详情，并与 Emby 服务端数据核对演员区域 | 页面其余详情正常显示；演员区域只展示 `Actor` 和 `GuestStar`，姓名、角色、头像和顺序与服务端有效数据一致；导演、编剧等非演员人物不混入。季详情不出现演员区域。 |
| A-02 | 使用同一人物重复出现、类型大小写或首尾空白不规范的真实条目 | 同一人物只显示一次；有效演员/客串演员身份和角色不被其他人物类型覆盖；页面无重复卡片或异常角色。 |
| A-03 | 验证有头像、无头像、无角色以及图片加载失败的演员 | 有效头像清晰显示且对应正确人物；无头像或图片失败时显示稳定占位，不出现破损布局；角色为空时不显示伪造内容。 |
| A-04 | 验证有有效人物 ID 和无有效人物 ID 的演员卡片 | 有 ID 的卡片可点击并打开对应人物页；无 ID 的卡片仍显示姓名和角色，但不可点击、无错误按钮语义且不会触发空 ID 请求。 |
| A-05 | 从电影、电视剧和单集演员卡片进入人物页 | 人物姓名、头像和可用简介对应所选人物；页面数据仅来自当前 Emby 服务器；不会打开错误人物或展示外部人物资料。 |
| A-06 | 验证无头像、无简介或人物详情请求失败的降级路径 | 已知姓名和头像信息仍可用；空简介区域隐藏；人物资料失败不阻断作品加载，并提供可恢复的局部重试；重试成功后替换为服务端资料。 |
| A-07 | 在原详情页滚动后进入人物页，再使用系统返回手势或返回键返回 | 返回到原详情页且原滚动位置保持；不会重复叠加页面、跳到错误详情或丢失已显示的演员数据。 |

## 3. 人物作品分页

| 编号 | 测试场景 | 通过标准 |
| --- | --- | --- |
| P-01 | 打开同时拥有电影和电视剧作品的人物 | “全部”只包含当前服务器可访问的 `Movie` 和 `Series`；不混入 `Episode`、`Season`、`Person` 等类型；总数和服务端同条件查询一致，默认顺序为首映日期降序。 |
| P-02 | 打开拥有 61 项以上作品的人物并连续滚动至末尾 | 首屏后按服务端分页继续加载，最终项目集合与服务端同条件查询一致；无缺项、重复项、顺序回退或无限加载；加载指示器不计入作品数。 |
| P-03 | 在“全部 / 电影 / 电视剧”间逐项切换并分别滚动分页 | 每次切换从新筛选第一页开始并回到作品网格顶部；类型、总数和后续分页均对应当前筛选，旧筛选结果不混入。 |
| P-04 | 在慢速网络下快速连续切换筛选 | 最终只显示最后一次选择的筛选及其总数；较早请求晚到时不能覆盖当前列表、追加错误分页或改变空状态。 |
| P-05 | 在第一页加载和下一页加载时分别断网或制造服务端错误，再恢复网络并重试 | 第一页错误可单独重试且不重复加载人物资料；下一页错误保留已加载作品并提供局部重试；重试后从正确索引继续，无重复或缺项。 |
| P-06 | 打开没有本地电影或电视剧的人物 | 显示明确空状态，不出现永久加载、虚假总数或来自其他人物的旧结果。 |
| P-07 | 从人物作品网格打开一个电影或电视剧，改变其收藏/观看状态后返回 | 返回后人物筛选、已加载分页和滚动位置保持；只刷新对应作品的用户数据，其他作品不被错误覆盖。 |
| P-08 | 分页过程中退出人物页、返回上级或把应用切到后台后再恢复 | 已销毁页面不显示晚到结果或异常提示；仍保留的页面不追加旧筛选结果；应用无崩溃。 |

## 4. 媒体库位置提示

| 编号 | 测试场景 | 通过标准 |
| --- | --- | --- |
| L-01 | 在真实媒体项目网格的顶部、中部和底部缓慢滚动，逐项核对首尾可见海报 | 浮层使用 1 基数显示真实首个和最后一个可见项目；最后一行不足一整行时不超过实际项目数；分母等于当前服务端结果总数。 |
| L-02 | 在仅加载第一页时滚动到底部，再跨越多个分页边界 | 首屏末尾不会显示 100%；下一页加入前后序号单调且连续，当前位置不会跳回 1；加载指示器和错误组件不计入序号；百分比按可见范围中点相对总数计算。 |
| L-03 | 分别执行触摸拖动、快速甩动和惯性滚动，再停止滚动 | 用户滚动和惯性滚动期间浮层保持可见；停止约 700 毫秒后淡出；新滚动会立即显示并取消旧隐藏计时；浮层本身不可拖动。 |
| L-04 | 在浮层显示区域继续滑动并点击其下方海报 | 浮层不拦截纵向滚动、海报点击或详情跳转，也不改变网格布局。 |
| L-05 | 切换排序、媒体类型、收藏、观看状态、流派、标签、文件夹和首字母筛选 | 新查询从顶部和第一页开始；旧范围、旧总数和旧百分比立即清除；新数据返回后只显示当前查询的范围和总数。 |
| L-06 | 在字母筛选及 STRM/普通媒体筛选生效时执行手动刷新 | 当前排序和筛选保持；刷新从正确服务端分页重新构建结果；首个服务端分页无本地匹配时继续读取同一查询的后续页，直至找到匹配、到达末页或出现错误；不会回退到未筛选结果。 |
| L-07 | 由真实 Emby 库变更触发后台实时刷新 | 刷新会重新加载恢复当前已浏览深度所需的分页并保持滚动位置；程序化位置恢复期间浮层保持隐藏，下一次用户主动滚动时才重新显示。 |
| L-08 | 在总数不足一屏及当前本地筛选无法得到可靠服务端总数的场景滚动 | 完整结果不足一屏时默认不显示浮层；总数未知时只显示可见范围，不显示伪造总数或百分比。 |
| L-09 | 在支持的横竖屏、不同窗口宽度和系统字体缩放级别下滚动 | 列数变化后首尾序号重新计算且与实际可见海报一致；浮层位于右侧安全区内，无裁切、文字溢出或系统栏遮挡。 |
| L-10 | 浏览媒体库根目录、文件夹/类型/流派/标签分组、图片库和搜索结果 | 这些非目标页面不显示媒体位置浮层；返回实际媒体项目网格后功能恢复正常。 |

## 5. `# / A-Z` 导航

| 编号 | 测试场景 | 通过标准 |
| --- | --- | --- |
| N-01 | 在实际媒体项目网格切换“名称 A-Z”、名称降序、其他排序及各类分组页面 | 字母入口只在名称升序的实际媒体项目网格出现；离开适用排序或进入分组页面时入口隐藏、已有字母筛选清除且结果恢复为当前非字母查询。 |
| N-02 | 点击收起入口展开字母栏，再点击“全部”、`#` 和多个字母 | 选项可准确命中；提交后字母栏收起，顶部标签显示当前筛选；关闭标签后从第一页恢复全部结果。 |
| N-03 | 从收起入口长按并连续拖过多个字母后松手；另做一次只长按不拖动 | 拖动期间中央预览与手指经过的选项一致，松手只提交最终字母；只长按不拖动时保持字母栏展开，不误选字符。 |
| N-04 | 选择有多页结果、单页结果和零结果的 A-Z 字母 | 结果与真实服务器相同字母查询一致；标签、总数、位置提示和所有后续分页均保持同一字母；零结果显示明确空状态。 |
| N-05 | 选择 `#` 并滚动到结果末尾 | 结果和真实服务器 `NameLessThan=A` 语义一致；所有分页持续使用符号条件，不混入 A-Z 或未筛选项目。 |
| N-06 | 使用数字、标点、中文、日文或其他非拉丁标题，以及显式自定义 `SortName` 的项目 | 每个项目的实际归类与当前 Emby Server 的排序名语义一致并被记录；无法归入 A-Z 的项目仍可通过“全部”和数字位置提示访问。 |
| N-07 | 在 STRM/普通媒体筛选下选择一个首个服务端分页无本地匹配、后续页才有匹配的字母，并执行刷新 | 客户端在同一字母查询内继续服务端分页直至找到本地匹配；刷新后行为一致；全部分页无匹配时进入正确空状态，不启动无字母条件的全库扫描。 |
| N-08 | 在慢速网络下快速选择多个字母，最后停在一个目标字母 | 只接受最后选择的结果；旧字母响应不得覆盖列表、总数、筛选标签、位置提示或后续分页状态。 |
| N-09 | 让服务器拒绝或不支持字母参数，然后重试或清除筛选 | 当前筛选显示局部错误和重试入口；不得静默回退为未筛选结果；清除筛选后才能重新加载全部结果。 |
| N-10 | 在紧凑横屏和右侧系统返回手势启用时点击、长按和拖动字母栏 | 全部选项可见且文字不重叠；应用字母手势与系统返回手势均可按明确起点完成，不发生高频误返回或误选。 |

## 6. 大型媒体库性能

| 编号 | 测试场景 | 通过标准 |
| --- | --- | --- |
| F-01 | 使用 Profile 构建，在 1000 项以上媒体库预热一次后，用 Flutter DevTools Performance 记录连续滚动至少 5 分钟并跨越不少于 10 个服务端分页；随后用 Release 构建重复核心滚动路径 | 记录 Flutter 与 DevTools 版本、采样起止时间并导出 Profile 时间线；设备单帧预算按 `1000 / 屏幕刷新率` 毫秒计算，UI 与 Raster 分别按“未超预算帧数 / 采样窗口总帧数”统计，结果均至少为 95%。UI 或 Raster 线程无单次 500 毫秒以上阻塞；Profile 与 Release 复核均无崩溃、ANR、OOM、黑屏或输入失去响应，分页请求期间仍可滚动和点击。 |
| F-02 | 在同一大型媒体库从顶部滚动到底部并返回顶部，共执行三轮；每轮结束后停在同一页面并空闲 30 秒，再用 `adb shell dumpsys meminfo <applicationId>` 以 5 秒间隔采集三次 `TOTAL PSS`，取中位数 | 项目不重复、不缺失，序号保持正确；以第一轮中位数为基线，第二、第三轮中位数各自与基线的差异不超过 15%，九个原始值、中位数和采样时间均写入结果；无持续单调增长或系统低内存杀进程。 |
| F-03 | 连续执行字母切换、媒体筛选、排序、刷新和翻页，并观察服务器请求 | 每次只加载当前查询需要的分页；不一次性下载整个媒体库，不出现失控的并发请求、重复页循环或旧查询持续翻页；操作期间界面仍可响应。 |
| F-04 | 在海报尚未全部缓存和海报已缓存两种状态下重复连续滚动 | 图片解码和缓存不会导致明显长时间停顿、错误人物/海报串图或内存持续增长；离屏图片加载不会阻断当前手势。 |
| F-05 | 连续旋转屏幕、进入作品详情再返回，并继续从当前位置分页 | 每次布局恢复后可继续滚动；无网格跳乱、重复加载全部历史页、位置提示高频闪烁或累积性性能下降。 |

| --- | --- | --- |
| D-01 | 在真实 ARM64 Android 设备安装目标构建，分别通过项目当前支持的局域网 HTTP 和有效证书 HTTPS 连接登录 Emby 并浏览上述页面 | 安装、启动、登录、认证图片和 API 请求均正常；两种连接路径的结果分别记录，不接受证书无效的 HTTPS 作为通过证据；应用进程无异常退出。 |
| D-02 | 使用触摸操作横向浏览演员、纵向滚动人物作品和媒体库、点击海报及筛选控件 | 横向与纵向手势方向明确，无明显抢手势；点击目标稳定，快速连续操作不触发错误页面或重复导航。 |
| D-03 | 分别使用 Android 手势导航和三键导航执行系统返回 | 人物页、作品详情和媒体库均只返回一级；筛选和滚动状态按对应场景保持；右侧字母栏及位置浮层不阻断系统返回。 |
| D-04 | 在带圆角、刘海或挖孔及不同导航栏高度的设备上测试右侧控件 | 演员内容、位置浮层、字母入口、展开字母栏、中央预览和筛选标签均位于安全区域，无系统栏遮挡或不可触达选项。 |
| D-05 | 在横屏、竖屏及系统字体 100%、最大支持缩放级别下重复核心流程 | 无文字重叠、裁切、按钮溢出或不可滚动区域；人物筛选、总数、位置范围和全部字母选项可读可操作。 |
| D-06 | 在人物或媒体分页请求进行中切后台、锁屏，再恢复应用 | 恢复后无崩溃、重复页面或旧请求污染；仍有效的页面可继续使用，已离开的页面不弹出晚到错误。 |
| D-07 | 在首屏和下一页请求期间分别断开 Wi-Fi、切换网络并恢复连接 | 界面保持响应；现有内容不被清空为错误数据；错误提示和重试可用；恢复后从正确筛选和分页继续。 |
| D-08 | 连续运行核心流程至少 15 分钟，期间多次进入/退出人物和作品详情 | 无 ANR、明显发热导致的持续失速、异常持续请求、资源泄漏导致的崩溃或返回栈异常增长。 |
| D-09 | 使用 TalkBack 检查演员卡片、人物筛选、海报、字母入口及清除标签 | 有 ID 的演员可识别为可操作控件，无 ID 演员不被宣告为按钮；筛选状态和字母选项有可理解标签，焦点顺序可完成核心流程。 |
| D-10 | 验收期间检查 Android 日志、错误文本、崩溃报告、抓包请求 URL/头部、可检查的图片缓存键和拟归档证据 | 访问令牌只出现在协议要求的登录响应和授权请求头中；不出现在日志、错误文本、崩溃报告、图片 URL、截图文件名、缓存键或归档证据中。含登录响应的原始抓包按 G-04 留在受控本机，不提交仓库。 |

## 8. 待验证风险

| 风险编号 | 待验证风险 | 关联场景 | 关闭标准 |
| --- | --- | --- | --- |
