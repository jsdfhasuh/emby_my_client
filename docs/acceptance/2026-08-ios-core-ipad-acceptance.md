## 安装说明

1. 从合并后 `main` 对应的 Actions run 下载 IPA，不使用实现分支 IPA 代替合并结果。
2. 核对下载文件的 SHA-256 与 `*.ipa.sha256` 完全一致。
3. 在 iPad 上将 IPA 通过文件 App、AirDrop 或其他设备所有者认可的方式放入本机。
4. 使用 TrollStore 的安装入口选择 IPA，确认应用显示为 `com.jsdfhasuh.embyclient`。
5. 启动应用并记录首次启动是否出现崩溃、白屏、无限加载或本地网络权限提示。
6. 覆盖升级测试时，先保留现有应用数据，再安装新 IPA；不要先卸载应用。
