# SyncPlay 能力验证与设计计划

更新日期：2026-07-30

状态：协议阻塞，不进入功能实现

## 1. 当前证据

Moonfin-Core 中找到的组播同步实现位于 Jellyfin 适配层，使用
`/SyncPlay/New` 等 Jellyfin SyncPlay API。当前分析没有在 Moonfin 的 Emby
适配层中找到对等实现，也没有证据证明目标 Emby 版本支持同一协议。

因此本项目不得：

- 将 Jellyfin `/SyncPlay/*` 路径直接发送到 Emby。
- 因路径返回非 404 就假设语义兼容。
- 在未验证时向用户显示可用的 SyncPlay 入口。
- 自行发明 Emby 私有 API 或用高频 seek 模拟服务端组播。

## 2. 用户场景

只有协议验证通过后才考虑：

- 创建、加入和离开同步播放组。
- 查看成员和组状态。
- 主持人控制播放、暂停、定位和切集。
- 处理网络时延、成员漂移、主持人离开和重连。

## 3. 非目标

- 不在首版支持跨不同 Emby 服务器的同步播放。
- 不使用第三方云中继保存 Token 或媒体 URL。
- 不把普通 Emby Remote Control 当作时间同步协议。
- 不保证异构设备达到逐帧同步。
- 不在没有服务端协调协议时实现点对点替代品。

## 4. 能力验证门槛

开始实现前必须取得至少一项可靠证据：

- Emby 官方文档明确公开组播同步 API；或
- 目标 Emby 服务器的公开能力响应声明该功能及协议版本；或
- 经授权的真实 Emby 测试环境和网络抓包确认完整消息语义。

验证报告需记录：

- 支持的 Emby Server 版本和客户端权限。
- 创建、加入、状态、播放命令、心跳、离开和错误响应。
- WebSocket 消息类型、顺序、时间单位和幂等规则。
- 服务器时间来源、往返时延估计和漂移纠正策略。
- 组关闭、主持人转移、断线重连和媒体不可用行为。

报告保存为新的本地协议文档，经确认后才能把本文件状态改为“可实施”。

## 5. 预留架构

仅预留接口，不在当前代码中增加空实现：

```text
GroupPlaybackCapability
GroupPlaybackApi
SyncGroup
SyncParticipant
SyncPlaybackCommand
ClockSample
SyncPlaybackCoordinator
```

如果 Emby 后续提供能力：

- `GroupPlaybackApi` 只负责已验证的传输。
- `SyncPlaybackCoordinator` 是组状态、时钟样本和命令序列的唯一所有者。
- `PlaybackController` 提供带会话令牌的 play、pause、seek 接口，不理解组成员。
- UI 只在 capability 为 true 时加载。
- 所有组和媒体 ID 同时绑定 `ServerScope`。

## 6. 同步算法要求

协议确认后才确定算法参数，但设计必须满足：

- 使用单调时钟计算本地间隔，不直接用系统墙钟做漂移判断。
- 多个时钟样本剔除高延迟异常值。
- 小偏差优先短时速率修正，大偏差才 seek。
- 所有命令带单调递增序号或服务端等价字段，忽略旧命令。
- 用户本地操作根据角色转为组命令或被明确拒绝，不能形成反馈循环。
- 换集先确认所有成员媒体可用，再推进组状态。

## 7. Android 和存储

- 协议本身预计不需要新增 Android 权限。
- 后台播放、画中画和网络切换沿用现有生命周期。
- 只持久化用户偏好，不持久化可过期的组会话和成员 Token。
- 诊断日志只记录匿名组 ID、命令序号、偏差和延迟摘要。

## 8. 测试计划

协议验证后建立确定性模拟时钟和虚拟传输：

- 创建、加入、离开、主持人转移和组关闭。
- 消息乱序、重复、丢失和延迟尖峰。
- 小漂移速率修正、大漂移 seek 和纠正冷却。
- 本地 seek 与远程命令反馈循环。
- 播放中换集、成员缺少媒体和服务器拒绝。
- 断网重连、旧组过期和应用前后台。

真机验收至少需要三台客户端和一台明确支持该协议的 Emby 服务器。

## 9. 发布策略

1. 完成 Emby 协议验证报告。
2. 增加隐藏的 capability probe 和传输契约测试。
3. 实现组生命周期，不接播放器。
4. 接入播放控制和模拟时钟测试。
5. 内部三设备验证。
6. 只对确认支持的服务器版本开放入口。

在第 1 步完成前，本项目状态保持“阻塞”，不估算功能交付日期。

## 10. GPL 边界

可以研究 Moonfin 的时间同步职责和状态机思想，但 Jellyfin SyncPlay API、模型和
实现不能复制或改名后用于 Emby。任何实现必须来自已验证的 Emby 协议和独立代码。
